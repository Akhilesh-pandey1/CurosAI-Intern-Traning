**HTML -** 

  


- Learn the purpose of HTML and how web pages are structured.   
  

- Understand the most commonly used tags (div, section, header, nav, form, input, button, image, etc.).  
  

- Don't try to memorize every HTML tag. Learn the commonly used ones and search for the rest when needed.  
  

- Resource :   
- [++https://www.142elements.com/++](https://www.142elements.com/)

  
  


**CSS -** 

  


- Understand :   
Box Model (Margin, Border, Padding, Content) ,  
Spacing (Margin &amp; Padding),   
Display (Block, Inline, Inline-block) ,   
Position (Static, Relative, Absolute, Fixed, Sticky),   
Flexbox,   
Grid,   
Responsive Design (rem, em, mobile responsive)  
  

- Don't spend hours memorizing CSS properties or every Flexbox value.  
  

- Use AI to generate layouts, but understand why the generated CSS works.   
  

- Remember, HTML and CSS and for design, so there is not much logic in it.  
  


### **Projects - **  
  
Generate the first version using AI. Then ask AI to explain every section. Make small changes yourself, observe what changes on the page, and keep experimenting. Understanding the generated code is more important than writing every line from scratch. 

### **Project 1 – Registration Form**

- Create a simple registration form.
- Use AI to generate the initial HTML.
- Ask AI to explain every tag used.
- Modify the form yourself (add/remove fields, change labels, add validation attributes).

### **Project 2 – Personal Portfolio Page**

- Create a simple portfolio page.
- Add heading, image, about section, skills, projects and contact information.
- Ask AI to improve the layout.
- Make your own design changes.
