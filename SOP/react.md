Reacts -

Understand what JSX is and how it differs from HTML.

Learn Conditional Rendering and Rendering Lists using map(). 


Understand Props and how data is passed between components. 


Understand the purpose of Hooks and why they are used. 


Types of Hooks. 
useState
useEffect 
useRef 


ES6 Modules : Import & Export, Default Export vs Named Export, Why every file in React is treated as a module. 


Don't try to memorize every Hook or React feature. Learn the commonly used concepts and search for the rest when needed.
