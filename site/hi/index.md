## Is site ko kaise use karein

- **Jo aata hai wo skip karo.** Koi check nahi karta, koi force nahi karta. Order follow karo, jo already aata hai uske upar se jump kar jao.
- **Jaise jaise aage badho, check-off karte jao.** Har page ke end mein "Maine kar liya" button hai. Progress isi browser mein save hota hai aur upar dots mein dikhta hai.
- **Ek page, ek baithak.** Chhota concept, ek-do video, hands-on, check-off. Phir ruk jao ya aage badho — aapki marzi.

## Learning approach — short mein

Ye poori site chaar aadaton par chalt hai:

- **Pehle why poocho.** Har concept par poocho: ye kya hai, ye exist kyun karta hai, kab use karte hain? Syntax search karke mil jaata hai — samajh nahi.
- **Code se pehle plan.** Requirement samjho, paper par ya diagram tool mein plan banao, tab keyboard chhuo. Code aakhri step hai, pehla nahi.
- **Ek time par ek change.** AI se ek chhota change maango, usse review karo, test karo, phir agla maango. Ek saath bahut changes karwane se mistakes chhup jaati hain.
- **AI ki supervision aap karte ho.** AI worker hai, aap supervisor. Kabhi mat bolo "AI ne ye kiya, mujhe nahi pata" — jo ship hota hai wo aapki zimmedari hai.

## Aap kya banoge

Shuru HTML/CSS aur JavaScript se hoti hai, phir React aur Python/Flask, phir database, terminal aur Git — aur end mein aap akela ek poora School CRM capstone banate ho. Captain ko sirf demo dikhta hai.
