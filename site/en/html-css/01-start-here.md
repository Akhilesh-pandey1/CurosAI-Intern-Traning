# 1.1 Start Here

Welcome to Module 1. Before any tags or styles, this page sets up two things: what HTML and CSS actually are, and the AI-first method you will use for everything you learn here.

## What HTML and CSS are

Think of a web page as a person:

- **HTML is the skeleton.** It gives the page its structure — this is a heading, this is a paragraph, this is a form, this is an image. Without HTML there is no page at all.
- **CSS is the skin and the clothes.** It decides how the page looks — colors, spacing, sizes, layout. Same skeleton, different clothes, completely different look.

That is the whole idea. HTML and CSS are for design, so there is not much logic in them. You describe *what* a page is (HTML) and *how it looks* (CSS), and the browser does the rest.

## The AI-first method: generate → ask → modify → observe

You will not type every line from scratch. This is how real work looks now:

1. **Generate** — Ask AI for something small: "Make a simple page with a heading and a paragraph."
2. **Ask** — Make AI explain every tag and every CSS rule it used. Ask cross-questions until you can explain it in your own words.
3. **Modify** — Change one small thing yourself. Make the heading red. Add a second paragraph.
4. **Observe** — Refresh the browser. See exactly what your change did.

Repeat that loop and understanding grows fast. Never copy AI's code blindly — the goal is that you can judge it, not that it types for you.

## User side vs server side — in basic words

- **User side (frontend)** — everything the browser does on the visitor's device. HTML, CSS, and JavaScript live here. Every visitor gets these files and runs them on their own phone or laptop.
- **Server side (backend)** — everything that happens on a computer you control, before the page arrives. It prepares the data: what the page shows, what it saves.

A simple rule: *if you can see it, click it, or watch it move, it is user side. If data must be stored, checked, or computed secretly, that is server side.* You will meet the server side properly in the Python module.

## Hands-on

1. Create a new folder, and inside it a file called `index.html`.
2. Ask AI: "Give me the smallest valid HTML page with a title and one sentence."
3. Save the file, then open it in your browser by double-clicking it.
4. Ask AI to explain every line. Change one word in the sentence, save, refresh the browser, and watch it change.

That loop — generate, ask, modify, observe — is the engine of this whole training.
